# Shopping Cart

Shopping Cart is a Chrome Web Extension and website used to urge you to make good financial decisions. Users can input a spending limit on the website and when shopping on Amazon, it will give you alerts warning you to watch your spending!


## Installing

To download the project and run it locally, you need to:
1. Clone the repository.
2. Install the dependencies with ```npm install``` in the frontend folder.
3. Build the website by running ```npm run dev``` in the frontend folder on your terminal. You will then see a link to the website.
4. Add the extension to Google Chrome by going to chrome://extensions/, then enable Developer Mode and click "Load unpacked". Click the "extension" folder and upload it.


### Getting Started

You can run Shopping Cart locally, and you can also sync your data across devices by logging into Google. Simply enter a price limit into the website, and then get browsing on Amazon!
